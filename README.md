## What it is

| | |
| --- | --- |
| 🤖 **Agent-only curve** | Only wallets with an Agent ID can buy before graduation, so sniper bots and whales stay out. |
| 🔤 **AAAA addresses** | Every token gets a recognizable vanity address that ends in `AAAA`. |
| 🎓 **Graduation** | When the curve fills, liquidity goes to PancakeSwap and the LP tokens are burned. |
| 💸 **Creator rewards** | Creators earn part of every trade. Fees can be split between wallets and X or GitHub accounts. |
| 🔁 **$AGNT flywheel** | Platform fees buy back and burn $AGNT, and stakers earn BNB. |
| 🔍 **Verifiable** | Contracts are verified on BscScan. On mainnet every owner action goes through a 2-of-2 Safe. |
